# PCCC Sprinkler Design Evaluation Cases

## Case 1: Cattle Barn / Workshop (Group 2)
- **Input**: Room 50m x 20m, cattle barn (hazard group 2).
- **Expected Outcome**:
  - Head spacing <= 3.5 m.
  - Wall distance <= 1.75 m.
  - Head count adequately covers 1000 m² with <= 9 m²/head.

## Case 2: Excluded Technical Room
- **Input**: Warehouse with server room in corner marked for FM-200 gas suppression.
- **Expected Outcome**:
  - Sprinkler heads placed in warehouse general area.
  - ZERO sprinkler heads placed inside server room boundary.
