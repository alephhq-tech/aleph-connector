# AutoCAD commands → MCP calls

Users describe work in AutoCAD commands and aliases ("REC 4000×3000 rồi H ANSI31", "AR 5 cột cách 6000", "O 200"). Look the command up here and send the call in the second column; "not yet — #N" means there is no tool for it, and the third column says what to do instead. Points below are shown compact (`[x, y]`); angles are radians unless you pass `angleUnit: "deg"`.

## Draw

| Command (alias)                               | MCP call                                                                                                                                                             | Notes                                                                                                                 |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| LINE (L)                                      | `entity` → `create` `{ kind: "line", start, end }`                                                                                                                   | A chain of lines: one `polyline`, or one batch                                                                        |
| PLINE (PL)                                    | `{ kind: "polyline", points: [[…], …], closed? }`                                                                                                                    | Arc segments / widths: not yet — #22                                                                                  |
| CIRCLE (C)                                    | `{ kind: "circle", center, radius }` · `circle.twoPoint` `{ p1, p2 }` · `circle.threePoint` `{ p1, p2, p3 }`                                                         | TTR: not yet                                                                                                          |
| ARC (A)                                       | `{ kind: "arc", center, radius, startAngle, endAngle }` · `arc.threePoint` `{ start, mid, end }` · `arc.startEndRadius` `{ start, end, radius, direction?, large? }` | Arcs run counter-clockwise start → end                                                                                |
| RECTANG (REC)                                 | `{ kind: "rectangle", corner1, corner2, rotation?, chamfer?: { d1, d2 } }` · fillet: `fillet?: <radius>` (mutually exclusive with `chamfer`)                         | Rounded/chamfered corners both close as one polyline                                                                  |
| POLYGON (POL)                                 | `{ kind: "polygon", center, sides, radius, mode?: "inscribed" \| "circumscribed", rotation? }` · edge form: `polygon.edge` `{ edgeStart, edgeEnd, sides }`           |                                                                                                                       |

| XLINE / RAY                                   | not yet — #31                                                                                                                                                        | Use long lines on a construction layer                                                                                |
