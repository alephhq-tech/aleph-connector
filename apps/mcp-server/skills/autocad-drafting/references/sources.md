Key principles drawn from Autodesk documentation:

- layers group objects by function and control properties such as color, linetype, lineweight, visibility, and plotting;
- annotation scale is intended to keep annotation at consistent output size;
- text styles control font and text characteristics;
- not every font supports every Unicode character;
- dimension scaling/annotation must match the intended model/layout workflow.
